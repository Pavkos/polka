# Полка

Спокойная оболочка для KOReader на Kindle с джейлбрейком: всё как на
Kindle, только по-русски и без лишнего.

- **Главная** — книга, которую вы читаете, и полки.
- **Библиотека** — книги по папкам-полкам, с обложками.
- **Статистика** — минуты за день, серии, год по дням, формуляр со
  штампами «Прочитано» и значки.
- **Чтение как на Kindle** — строка «Осталось в главе», тулбар сверху,
  панель «Aa», меню выделения, экран мигает только на новой главе.
- **Инструменты** — все цитаты, книги по Wi‑Fi с телефона, OPDS‑каталоги,
  Instapaper и сайт.
- **Сайт** — читательский билет: статистика и цитаты в телефоне, книги
  оттуда на Kindle, место в книге между Kindle и Xteink.

Полка сама обновляется (Настройки → «Версия»), а в заголовках и
вопросах о выходе и перезапуске называет приложение «Полкой».

## Установка

С KPM (менеджер пакетов для Kindle): в поиске на Kindle наберите

    ;kpm install polka

Вручную: подключите Kindle к компьютеру, скопируйте папку
`polka.koplugin` в `koreader/plugins/` и перезапустите KOReader. Полка
откроется сама.

Проверена на KOReader 2026.07.1.

## Сайт

Инструменты → «Сайт» → «Подключить». На экране появится код и QR‑код:
наведите на него камеру телефона (или откройте сайт и введите код) и
придумайте пароль. Kindle подключится сам и покажет номер билета.

На сайт с телефона можно войти без пароля: Сайт → «Войти на сайт с
телефона» покажет одноразовый код.

## Как удалить

Удалите с Kindle:

- `koreader/plugins/polka.koplugin`;
- `koreader/patches/1-polka-brand.lua`;
- `documents/polka.sh`, если добавляли «Полку» на экран Kindle (или
  О Полке → «Убрать» до удаления).

Перезапустите KOReader — он будет таким же, как до Полки. Если Kindle
подключён к сайту, сначала нажмите Сайт → «Отключить этот Kindle» (или
уберите его на сайте, в списке устройств).
